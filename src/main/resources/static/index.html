创建消息模板

需登录

使用说明

模板是发送的前提。创建并启用后会跳到「发送与定时」，按模板名称选中并自动带出主题和变量。

  • 内容里的 ${变量} 会在发送时替换；没填的变量会替换成空，不会把 ${xxx} 原文发给用户。
  • 选择「飞书」渠道即可通过已配置的机器人真实推送。
  • 「业务来源」用于限流分组，可自定义命名。查询与发送均按当前登录用户隔离。

发送 / 定时消息

需登录
选中后会自动带出主题和模板变量，无需再手填编号。
批量短信：业务侧提供名单，中台按模板逐条投递（单次最多 200 人）。
来自所选模板，切换模板会同步更新。
立即发送与定时发送使用同一套完整消息体；定时消息会先进入等待队列，到点后再走相同的推送链路。提交后可在「消息记录」查看状态。 短信批量发送由中台拆分收件人逐条入队；业务系统只需把名单交给中台，不必自己循环调短信网关。
